# ARISE Workspace Customizations & Behavioral Rules

## Git Discipline & GitHub Sync Rule
- **Always Commit & Push to GitHub**: Whenever completing a coding task, feature modification, bug fix, or documentation update, automatically commit the changes with descriptive commit messages and push them to GitHub (`https://github.com/0xaje/Arise.git` on branch `main` or active feature branch).
- **Secret Hygiene**: Ensure `.env` and sensitive credentials are never tracked or committed to Git.
