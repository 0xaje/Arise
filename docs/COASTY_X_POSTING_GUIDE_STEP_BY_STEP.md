## 🛠️ Step 0: Initial Setup & Local UI Preparation

1. **Launch the Local Web App**:
   Open terminal and start the web app:
   ```bash
   npm run dev
   ```
   Open your browser to: **`http://localhost:5173`** (or your live Vercel URL).

2. **Open X (Twitter)**:
   - Go to `https://x.com` and open the **Tweet Composer** by clicking the **"Post"** button.
   - Look for the **`+` (Add Tweet)** button at the bottom right of the composer. You will build the whole 8-tweet thread in one go before hitting **"Post All"**.

```

2. Paste Tweet #1 text ➔ Attach the 75s Video.
3. Click the [+] button at the bottom right of the composer box.
4. Paste Tweet #2 text ➔ Attach Screenshot #2.
5. Click [+] again ➔ Paste Tweet #3 text ➔ Attach Screenshot #3.
6. Repeat for Tweets #4, #5, #6, #7, and #8.
7. Double check all 8 tweets are attached sequentially in the draft.
8. Click "Post All" (or "Unroll All")! 🎉
```
